# أذكاري

موقع أذكار الصباح والمساء مع مسبحة إلكترونية وملاحظات خاصة بكل مستخدم.

## المميزات
- أذكار الصباح والمساء من كتاب «حصن المسلم»
- مسبحة إلكترونية تفاعلية
- تسجيل دخول وإنشاء حساب
- بيانات خاصة بكل مستخدم (localStorage)
- ملاحظاتي - خانة لكتابة ملاحظاتك الشخصية
- دعم كامل للغة العربية (RTL)
- تصميم احترافي متوافق مع الجوال

## الرابط
https://s3alr.github.io/adhkari/

## طريقة الاستخدام
1. سجل دخولك أو أنشئ حساباً جديداً
2. اقرأ أذكار الصباح أو المساء وحدد كل ذكر أكملته
3. استخدم المسبحة لعد التسبيحات
4. اكتب ملاحظاتك الشخصية في خانة «ملاحظاتي»

모든 البيانات محفوظة في متصفحك فقط ولا يمكن لأي مستخدم آخر الوصول إليها.
